## Limitaciones

- El PDF provisto manda sobre el alcance curricular y la documentación oficial de Playwright manda sobre los hechos técnicos. El PDF menciona JavaScript, TypeScript, Python y .NET, mientras la documentación vigente también incluye Java; Java queda fuera porque no forma parte del programa provisto.
- La expresión "sin presupuesto" del nombre del archivo solo describe que el curso todavía no cuenta con presupuesto; no se interpreta como una limitación curricular ni como una obligación de usar exclusivamente herramientas gratuitas.
- Las instantáneas técnicas corresponden a Playwright `1.62.1`, la versión publicada en npm al 2026-08-28. La documentación viva puede cambiar después de esa fecha.
- La mayoría de las fuentes técnicas están en inglés y el contenido se redactará en español latinoamericano. Los nombres de API, comandos y mensajes literales se conservarán cuando traducirlos alteraría su significado.
- El syllabus de ISTQB es mucho más amplio que este curso y no convierte el tema en preparación para una certificación. Se usará solamente para definiciones generales requeridas por el módulo 1.
- Las páginas de Selenium y Cypress son descripciones de sus propios proveedores. Se usarán para una comparación de alto nivel y se evitarán afirmaciones competitivas no sustentadas de forma neutral.
- No se proporcionó una aplicación bajo prueba. Para que los laboratorios sean reproducibles y no dependan de servicios externos inestables, el esquema propondrá ejercicios autocontenidos con fixtures locales.
- TypeScript fue confirmado como lenguaje de ejemplos y laboratorios porque el programa exige Node.js/npm y la instalación oficial lo ofrece como opción predeterminada.
- No se identificaron brechas de evidencia que impidan cubrir los siete módulos del programa.
